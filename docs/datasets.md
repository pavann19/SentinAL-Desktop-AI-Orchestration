# Evaluation datasets

| Input | Purpose |
|---|---|
| `eval/intent_dataset.json` | 3,230 versioned intent-labelled synthetic examples |
| `eval/intent_dataset_ood_test.json` | 190 synthetic OOD examples |
| `eval/real_world_massive_ood.json` | 11,387 mapped real-world examples; each record includes source and original label |
| `eval/regressions/` | Small targeted routing examples retained from research |
| `eval/tasks.yaml` | Pipeline task expectations |
| `benchmarks/external/manifests/` | Declarative external task definitions with attribution |
